プライバシーポリシー

chokocamp-shorts（以下「本ツール」）は、YouTube チャンネル「ちょこきゃんぷ」の運営者が自分のチャンネルを管理するためだけに使う個人用ツールです。

取得する情報

本ツールは、運営者本人が Google アカウントで許可した範囲で、YouTube Data API と YouTube Analytics API を通じて、運営者のチャンネルの動画情報と成績（再生数、視聴時間など）を取得します。また、運営者が作成した動画を運営者のチャンネルにアップロードします。

情報の使い方と保存

取得した情報は、運営者のチャンネルの投稿計画と成績分析にのみ使います。情報は運営者が管理する非公開の環境に保存し、第三者に提供・販売することはありません。

YouTube と Google について

本ツールは YouTube API サービスを利用しています。YouTube 利用規約と Google プライバシーポリシーもあわせてご確認ください。許可の取り消しは Google アカウントの権限設定から行えます。

お問い合わせ

本ツールに関するお問い合わせは、YouTube チャンネル @chokocamp までご連絡ください。

English summary

chokocamp-shorts uses YouTube API Services. With the channel owner's permission, it accesses only our own channel's video information and analytics, and uploads our own videos. The data is used only for our own posting plans and analytics, stored in a private environment, and never shared or sold. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at Google Account permissions.
